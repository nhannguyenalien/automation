Bản mới nhất từ GitHub

Google AI Browser Worker

Nút bên dưới luôn tải file ZIP của bản extension mới nhất. Khi có bản cập nhật trên GitHub, đường dẫn này tự chuyển sang bản mới — không cần đổi bookmark.

Tải extension mới nhất (.zip) Xem ghi chú phiên bản
  1. Giải nén file ZIP.
  2. Mở chrome://extensions hoặc edge://extensions.
  3. Bật Chế độ dành cho nhà phát triển, chọn “Tải tiện ích đã giải nén”, rồi chọn thư mục vừa giải nén.
